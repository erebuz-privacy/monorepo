---
title: Quickstart
description: Quote a transfer, create it, and track it to completion.
---

Erebuz provides an HTTP API for private cross-chain transfers. Set `BASE_URL` to your deployment (locally, `http://localhost:3000`). Every response is JSON of the form `{ "success": boolean, "data": ... }`.

<Steps>
<Step>

## Quote

Ask what the recipient receives for a given input. Nothing moves and no address is allocated, so this is safe to call on every keystroke.

```bash
curl -X POST $BASE_URL/api/private-route/quote \
  -H 'content-type: application/json' \
  -d '{
    "sourceChainId": 8453,
    "destChainId": 137,
    "amount": "100",
    "tokenSymbol": "USDC",
    "destTokenSymbol": "USDT"
  }'
```

The `data` holds `quotedOutputAmount` and `feeAmount` (smallest units of the destination token), the USD values, `etaSeconds`, and a `route` for display. Re-quote every 15 to 20 seconds; the price is live.

</Step>
<Step>

## Create

Commit the transfer. This allocates the deposit address to fund.

```bash
curl -X POST $BASE_URL/api/private-route \
  -H 'content-type: application/json' \
  -d '{
    "sourceChainId": 8453,
    "destChainId": 137,
    "amount": "100",
    "tokenSymbol": "USDC",
    "destTokenSymbol": "USDT",
    "userDestinationAddress": "0xRecipient"
  }'
```

Send the input amount to `depositAddress` on the source chain. Keep the returned `routeId` to track the transfer.

</Step>
<Step>

## Track

Poll until the status is terminal.

```bash
curl $BASE_URL/api/private-route/$ROUTE_ID
```

Status moves `AWAITING_DEPOSIT` to `COMPLETED` (or `FAILED`). See [Reference](/docs/reference) for the full lifecycle.

</Step>
</Steps>

## Populate the selectors

To build a token and chain picker, list what Relay can bridge:

```bash
curl $BASE_URL/api/relay/chains
curl "$BASE_URL/api/relay/tokens?chainId=42161&search=USDC"
```

`tokenSymbol` and `destTokenSymbol` can differ, so a transfer can change both chain and token (for example USDC on Base to USDT on Polygon). Omit `destTokenSymbol` to keep the same token.
