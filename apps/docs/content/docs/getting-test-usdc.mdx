Get test USDC on a supported testnet to send private transfers.

## Circle Faucet

The Circle Faucet covers every CCTP-supported testnet in one place.

→ Open [faucet.circle.com](https://faucet.circle.com)

   [![Circle Faucet screenshot](/images/circle-faucet.png)](https://faucet.circle.com)

→ Select your chain from the list below
→ Paste your wallet address → click **Send 20 USDC**

Tokens arrive in under a minute. Developers can request **20 USDC** every **2 hours**, per address, per chain.
